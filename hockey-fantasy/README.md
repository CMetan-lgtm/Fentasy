# Калькулятор фэнтези КХЛ (sports.ru)

Локальное веб-приложение для команды sports.ru **587717** («Царь Леонидс», турнир КХЛ 107, лига «Улитки Кокарева»).
Каждый пересчёт загружает свежие данные напрямую с sports.ru.

План и логика «как занять первое место» — в [PLAN.md](PLAN.md).

## Что умеет

- **Свежие данные при каждом пересчёте:** состав, цены и очки всех 699 игроков пула, статистика матчей, календарь КХЛ, таблица клубов, таблица лиги и составы всех 49 соперников.
- **Прогноз очков** по каждому игроку на неделю и до конца сезона (с учётом матчей клуба, доли игр, силы соперника).
- **«Кого на кого менять»:** одиночные замены с разницей очков на неделю и до конца сезона.
- **Варианты трансферов:** лучший состав при 0–5 заменах (лимит 5 в неделю, бюджет, лимит 3 игрока из клуба, блокировки) и идеальный состав без лимита.
- **Шансы на 1-е место** в лиге на неделю и на сезон (Монте-Карло), варианты с разным риском.
- **Экспорт:** состав и очки (CSV, JSON), все игроки с прогнозом (CSV), сырой снимок sports.ru (JSON).
- **История снимков** в `data/history/` для проверки прогноза.

## Запуск

Нужен Node.js 18 или новее (используется встроенный `fetch`). Внешних зависимостей нет.

```bash
cd hockey-fantasy
node server.js
```

Откройте http://localhost:3000. Переменные окружения: `PORT` (по умолчанию 3000), `HOST` (0.0.0.0), `TEAM_ID` (587717).

Обновить данные и файлы экспорта без веб-интерфейса:

```bash
node scripts/refresh.js
```

## Как пользоваться

1. При открытии страницы сначала показываются сохранённые данные, затем автоматически загружаются свежие (≈10 с).
2. Кнопка «Пересчитать с sports.ru» (и любое изменение параметров) запускает полный цикл: загрузка с sports.ru → расчёт.
3. Параметры:
   - **Горизонт**: от 1 до 4 недель по календарю;
   - **Риск**: от −1 (агрессивно, ставка на разброс) до +1 (осторожно);
   - **Замен на неделю**: по умолчанию сколько осталось на сайте.
4. Разделы страницы: Состав · Кого на кого · План трансферов · Лига и 1-е место · Все игроки · Расписание недели · История и экспорт · Логика.

## Источники данных

| Что | Адрес |
|---|---|
| Состав команды (17 игроков, цены, очки, блокировка) | `https://www.sports.ru/fantasy/hockey/team/json/{id}.json` |
| Все игроки турнира (699, цены, стартовые цены, очки) | `https://www.sports.ru/fantasy/hockey/team/create/107.json` |
| Бюджет, баланс, трансферы, неделя, дедлайн, места | `https://www.sports.ru/fantasy/hockey/team/{id}.html` |
| Таблица лиги (ОТ — очки тура, ОС — стоимость + баланс) | `https://www.sports.ru/fantasy/hockey/league/{id}.html` |
| Статистика игроков КХЛ (матчи, голы, передачи, +/−, штрафные, время, сейвы) | `https://www.sports.ru/gql/graphql/` (тот же запрос, что у виджета статистики) |
| Календарь КХЛ (даты и команды матчей) | `https://www.sports.ru/hockey/tournament/khl/calendar/` |
| Таблица клубов (игры и очки для силы соперника) | `https://www.sports.ru/stat/gadget/107.html?sport_id=209&is_full=1` |

## Допущения и ограничения

- Правила не указывают, сколько длится блокировка игрока после матча. В расчёте принято 150 минут (настройка `lockAfter` в `lib/model.js`).
- Одна замена считается одним трансфером; бюджет = стоимость состава + баланс (это ОС команды, проверено на четырёх командах).
- Прогноз не знает травм, дисквалификаций и новостей. Составы соперников берутся на момент пересчёта и считаются неизменными.
- Сезонный горизонт приближённый: средние 2,34 матча клуба в неделю до 23 мая 2027.
- Вероятности 1-го места — оценка Монте-Карло, а не гарантия.
- Сервер отдаёт данные с заголовком `Access-Control-Allow-Origin: *`, поэтому запускайте его локально или в доверенной среде.
- Если сайт не ответил, интерфейс покажет, какой источник сбоил (предупреждения и статус загрузки в шапке).

## Проверка данных (сделано при сборке)

- `цена − стартовая цена = очки сезона` у всех 699 игроков;
- `ОС = стоимость + баланс` у нашей команды и у трёх соперников;
- 598 из 699 игроков сопоставлены со статистикой по `tag_id`; 589 из них имеют матчи в этом сезоне, остальные 110 ещё не играли.
